# H-LUX Puzzle Studio

Jogo de quebra-cabeças com as suas próprias fotos. Funciona no navegador do celular e do computador e pode ser instalado como app (PWA).

- Imagens processadas e salvas apenas no dispositivo (IndexedDB).
- 12 a 1.000 peças com encaixes gerados proceduralmente.
- Funciona offline depois do primeiro acesso.
